# FE-RENDER-002: CSS Module 类名连字符与下划线不匹配导致所有样式失效

- **分类**: RENDER
- **问题现象**: CSS文件中类名使用连字符（.app__sidebar-left），TSX中用下划线访问（styles.app__sidebar_left），CSS Module键名不匹配，类名返回undefined，所有样式完全不生效，布局崩溃
- **修复方式**: 统一CSS Module文件中所有类名：将选择器里的连字符全部改为下划线。用 perl -i -pe 's/(?<=[.\w])-([\w])/_$1/g if /^\s*\./' 批量修复。根本原则：CSS Module文件的类名要与TSX中的访问方式保持完全一致
