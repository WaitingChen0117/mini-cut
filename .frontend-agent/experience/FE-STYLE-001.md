# FE-STYLE-001: Demo2 配色体系：中性灰，禁止蓝色调硬编码

- **分类**: STYLE
- **问题现象**: 早期用蓝色调（#1a1a2e, #0a0e18, #1a2235）作为背景，用户要求改为中性黑灰
- **修复方式**: 全部替换为 CSS 变量：`--bg-primary:#000`（App背景/divider）、`--module-bg:#1c1c1c`（模块主体）、`--module-header-bg:#141414`（模块头部/toolbar）、`--border:#2a2a2a`、`--bg-hover:#252525`。新增 CSS 禁止硬编码蓝色调
- **确认次数**: 1
- **应用记录**: globals.css + 所有组件 .module.css
